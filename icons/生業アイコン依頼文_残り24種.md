# 祖先遡行録 生業アイコン依頼文（残り24種・job_182〜205）

## 使い方

1. 下の「依頼文」を、画像を作れるAI（ChatGPT、Gemini など）にそのまま貼り付けます。
2. 続けて「バッチ 1」の表を貼り付けて送ります。
3. できあがったら「次のバッチです。絵柄は前と同じにしてください。」と添えてバッチ 2 を送ります。
4. 届いた画像は、表の「ファイル名」で保存してください（例：`job_182.png`）。

---

## 依頼文（ここから下を貼り付け）

あなたはゲームのアイコンデザイナーです。日本の歴史をさかのぼるオカルト風の読み物ゲーム「祖先遡行録」で使う、**祖先の生業（職業）のアイコン**を作ってください。残り24種あり、20個ずつ表で送ります。

### ゲームの世界観

プレイヤーは実家で見つけた「渦の印」の木箱をきっかけに、自分の祖先を現代から縄文・氷河期までさかのぼるゲームです。このバッチは明治時代〜奈良時代の祖先です。

### 絵柄（全アイコン共通・必ず守ってください）

すでに181種のアイコンが完成しており、**その絵柄に合わせてください**。

- **ちびキャラ（頭身2〜3）の日本人男女**が中心にいる。顔は丸くシンプルで、目は大きめ、口と鼻は省略可。
- **楕円形・丸形の白いフチ**の中にキャラと背景を収める（外側は白無地）。
- 背景はその時代・仕事に合った**簡単な景色や道具**（屋外なら空や地面、屋内なら部屋の雰囲気）。
- キャラは**その生業の動作・道具**を持っている（鍛冶なら鎚、漁師なら網や竿）。
- **時代に合った服装・道具**にする（明治の工場労働者なら作業着、江戸の飛脚なら脚絆・菅笠）。
- **ピクセルアート調またはアニメ調**のどちらでも可。線は太めでくっきり。
- **正方形 1024×1024px**。楕円フチの外は白（#FFFFFF）の無地。
- **文字・数字・記号は入れない**（ファイル名を書く欄の外は完全に不要）。
- **複数枚を1枚にまとめる場合**は、**5列×4行の格子**に並べ、各マスの下にファイル名（例：`job_182`）を小さく添えてください。

### 表の見方

- **ファイル名**：画像ごとにこの名前を付けてください。
- **生業**：その祖先の職業。キャラのポーズや道具の中心にしてください。
- **時代・場所**：服装・背景・道具の参考に。
- **性別**：キャラの外見の参考に。
- **気配**：海・星・地・火・書のどれか。背景の色調の参考に（海＝青、星＝夜・紺、地＝茶・黄土、火＝赤・橙、書＝落ち着いた茶）。
- **どんな人か**：ポーズや表情の参考にしてください。

### 出力のしかた

- **5列×4行**（20枚分）を1枚の画像にまとめ、各マスの下にファイル名を小さく添えてください。
- 4枚しかない最後のバッチは、4枚だけ並べてください。
- 準備ができたら「了解」とだけ返し、表を待ってください。

## 届いた画像のゲームへの組み込み方

画像が届いたら、以下の手順でゲームに組み込めます。

```bash
cd ~/Workspace/sokou-koroku

# グリッド画像（5列×4行）を切り出す（最初の番号を指定）
python3 tools/cut_icons.py 182 バッチ1の画像ファイル.jpg

# バッチ2（4枚のみ）は個別に処理するか、同じコマンドで
python3 tools/cut_icons.py 202 バッチ2の画像ファイル.jpg

# job_iconjs に再パック
python3 tools/pack_icons.py

# ゲームをビルド
python3 tools/build.py

# Gitにコミット・プッシュ
git add icons/cut/ content/job_icons.js index.html
git commit -m "生業アイコンをXXX種に拡充"
git push
```

単体画像（白背景）で届いた場合も、cut_icons.py でなく手動で `icons/cut/job_XXX.png` に保存した後、`pack_icons.py` → `build.py` の手順で組み込めます。
