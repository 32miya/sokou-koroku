# 祖先遡行録 — オカルト血統診断

**あなたの血は、どこから来たか。**

9つの問いに答えるたびに、一族の血の気配（海・星・地・火・書）が積み重なる。現代から縄文・氷河期まで祖先をさかのぼり、最後に一族の「起源」にたどり着く読み物ゲーム。

**▶ 遊ぶ**: https://32miya.github.io/sokou-koroku/（スマホ・パソコンのブラウザで開くだけ）

---

## どんなゲームか

- **診断系**：選んだ答えが血の気配を決め、5種類のオカルトな起源（ムー大陸・シリウス・アガルタ・超古代文明・時間の外側）のいずれかにたどり着く
- **読み物系**：問いと祖先の記録はすべて時代の口調で書かれている。昭和の下町語、江戸の町人言葉、平安の古文、縄文のカタコトと、遡るほど言葉が変わる
- **毎回ちがう**：たどる時代も、問いの言い回しも、祖先の名前も、遊ぶたびに入れ替わる。系譜の組み合わせは194,400通り × 結末5種

## こんな人に

スピリチュアル・オカルトが好き／先祖や血のルーツが気になる／診断コンテンツが好き／歴史読み物が好き
